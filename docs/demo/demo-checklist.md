# 編輯器 Demo 逐步清單（邊錄邊照著做）

> 用法：從上到下一步一步做，每步打勾。每步格式 = **做什麼** → ✅ **要看到什麼** → 🎤 **可以講的一句話**。
> 詳細版在 `editor-demo-script.md`；這份是錄影時照著念的精簡版。
> 預估 8–12 分鐘。

---

## ⏱ 第 0 步：錄影前準備（這段不要錄進去）

- [x] 終端機跑 `docker compose ps`，確認 `neo4j`(healthy) / `backend` / `frontend` 三個都 **Up**。
- [x] 瀏覽器開 `http://localhost:3000/zh-Hant/editor`，看到 **空的文件列表（0 篇）**。
- [x] 右上角語言設成 **繁體中文**、主題設成 **淺色**（錄影較清楚）。
- [x] 視窗拉寬到 **1440 以上**（工具列才完整）。
- [x] **暖機**：先把 `sample-thesis-draft.md` 匯入、跑一次「缺陷檢查」成功後，把這份刪掉。（避免正式錄時第一槍卡 Neo4j）
- [x] 把 `docs/demo/sample-thesis-draft.md` 放到桌面備用。
- [x] 開始錄影 🔴。

---

## 1️⃣ 匯入草稿 + 自動儲存（約 40 秒）

- [x] 文件列表頁點 **匯入文件** → 選 `sample-thesis-draft.md`。
  - ✅ 自動進編輯器，標題顯示「基於知識圖譜的學術論文邏輯缺陷自動偵測方法」，左側大綱列出五章。
- [x] 在標題列改一兩個字。
  - ✅ 右上徽章「儲存中 → 已儲存」。

- 🎤 「支援 Markdown/Word/LaTeX 匯入，邊打邊自動存檔。」

## 2️⃣ 基本排版 + Slash 選單（約 60 秒）

- [x] 選一段字，按 **粗體**、切 **H2**。
- [x] 空白行打 `/` → 插入 `/表格`、`/數學`（公式）、`/目錄`。
- [x] 右側 **引用樣式** 下拉切 APA ↔ IEEE。
  - ✅ 公式有渲染、目錄自動生成、樣式即時改變。

- 🎤 「公式、表格、目錄都是原生區塊，所見即所得。」

## 3️⃣ 大綱導覽 + 尋找取代 + 寫作進度（約 40 秒）

- [x] 點左側大綱「研究方法」→ 跳到該章。
- [x] 按 `Cmd/Ctrl + F`，搜「方法」，看高亮與計數。
- [x] 點標題列 **靶心圖示**，輸入目標字數 20000。
  - ✅ 出現進度條與各章字數。

- 🎤 「長文導航、進度與各章字數一目了然。」

## 4️⃣ AI 自動補全（約 40 秒）

- [x] 在某段句尾接著打「…其核心貢獻在於」，停一秒（或按 `Cmd/Ctrl + J`）。
  - ✅ 出現灰色 ghost text 建議。
- [x] 按 `Tab` 接受。

- 🎤 「像 Copilot 的寫作版，會讀整篇上下文。」

## 5️⃣ 改寫面板（約 50 秒）

- [x] 選句子「實驗顯示本方法的效果非常好，使用者滿意度極高。」→ 浮動選單點 **改寫**。
- [x] 點預設 **學術化** → 看串流結果 → 也試自訂指令「縮短成一句」。
- [x] 點 **採用**。

- 🎤 「七種預設＋自由指令，先預覽再採用。」

## 6️⃣ 大綱生成器（約 40 秒）

- [x] 工具列 **大綱** → 點 **IMRaD 範本** 插入標準骨架。
- [x] 下方輸入主題「論文邏輯缺陷偵測」→ **生成** → **插入**。
  - ✅ 串流產出多層標題樹。

- 🎤 「從零寫論文時，先讓 AI 搭好章節骨架。」

## 7️⃣ 智慧引用：搜尋→插入→驗證→溯源（約 90 秒）⭐

> ⚠️ **用英文查詢**效果最好。

- [x] 工具列 **引用搜尋** → 輸入 `attention mechanism long-range dependencies transformer` → 搜尋。
  - ✅ 出現相關文獻（Transformer-XL 等），附相似度分數。
- [x] 在某句後點某篇 **插入** → 文中出現引用 chip。
- [x] 點 **驗證（紅綠燈）**。
  - ✅ 顯示 綠/黃/紅 ＋ 證據句 ＋ 理由 ＋ 信心值。
- [x] 點 **溯源** → 列出最支持的全文句子。

- 🎤 「不只找引用，還幫你查證『這篇真的支持你這句嗎』，對抗亂引。」

## 8️⃣ 引用重新連結 + 批次驗證（約 50 秒）

- [x] 引用面板點 **重新連結（Relink）**。
  - ✅ 把底部純文字參考文獻 + 內文 `(Vaswani et al., 2017)` 升級成活引用（會連到 Vaswani）。
- [x] 工具列點 **驗證全部引用** → 批次跑紅綠燈。

- 🎤 「舊稿匯入的死引用，一鍵救回成可查證引用。」

## 9️⃣ 缺陷檢查 + 一鍵 AI 修正（約 90 秒）⭐⭐ 主秀

- [x] 工具列點 **缺陷檢查（盾牌）** → 等幾秒。
  - ✅ 右側列出缺陷，會抓到：
    - REL-01 主張無證據／REL-06 概念未定義／**REL-04・REL-08 跨章節（高）**／REL-12 結論未回扣。
- [x] 點某條 **定位** → 編輯器高亮並跳過去。
- [x] 點 **AI 修正** → 自動開改寫面板生成修正 → **採用**。

- 🎤 「核心賣點：不是抓錯字，是抓**論證結構**——主張有沒有證據、章節有沒有對上。做法是先把論文拆成知識圖譜，再用 13 條規則逐條檢查，所以講得出理由、可重現。這正是我論文 ablation 要證明的。」

## 🔟 文法 Lint + 一鍵修正（約 40 秒）

- [x] 工具列點 **Lint** → 即時掃描。
  - ✅ 列出三類：半形標點（成功**,**Transformer）、中英無空格（使用**GraphRAG**技術）、標點前空格。
- [x] 點 **全部修正** 一次清乾淨。

- 🎤 「中文論文的標點/空格瑕疵，規則式即時抓、零成本一鍵修。」

## 1️⃣1️⃣ 版本歷史（約 40 秒）

- [x] 工具列 **版本歷史** → 命名「Demo 快照」→ **儲存**。
- [x] 故意刪一段字 → 在清單點快照 → **還原**。
  - ✅ 內容復原（還原前自動備份，可再反悔）。

- 🎤 「自動存檔＋手動快照＋可逆還原。」

## 1️⃣2️⃣ 匯出多格式（約 90 秒）⭐

- [x] 工具列 **匯出** → 模板選 **台灣論文**、勾 **包含封面**（欄位已預設好）。
- [x] 點 **PDF（台灣論文）**。
  - ✅ 新分頁開 PDF，**第一頁是雙語封面**（長庚大學／碩士論文／指導教授 張禾坤博士），內文中文正常。
- [x] 再點 **DOCX**、**LaTeX**、**HTML 預覽** 各示範一下。

- 🎤 「同一份內容一鍵輸出多格式；PDF 走真正的 XeLaTeX，直接產出台灣碩論格式。」

## 1️⃣3️⃣ 專注 / 深色 / 語言（約 40 秒）

- [x] 工具列 **專注模式** → 介面淨空 → `Esc` 離開。
- [x] 右上切 **深色模式**。
- [x] 右上 **語言** 切 English → 介面變英文 → 切回繁中。

- 🎤 「完整 i18n、深色模式、專注寫作——產品完成度。」
